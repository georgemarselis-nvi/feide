**Before you read this**

This document assumes you already know LDAP: schemas, object classes, the directory tree, distinguished names, and how a server is configured. If you do not, read one of these first, all of it:

- Gerald Carter, *LDAP System Administration*, O'Reilly, 2003, ISBN 978-1-56592-491-8
- Matt Butcher, *Mastering OpenLDAP*, Packt, 2007, ISBN 978-1-84719-102-1

This document is not only for universities. Feide has two information models: the model for lower education, which covers primary and secondary schools, and this one, the model for higher education, which covers everyone else. If your organisation is a university, a university college, a research institute or any other public body that is not a school, the higher-education model is the one you must follow. Sections about students are simply empty for organisations without them.

The norEdu* schema is available as a ready-to-load file: [52-noredu.ldif](LINK). It depends only on core, cosine and inetorgperson.
